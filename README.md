# TakaFlow

Offline-first smart personal expense & finance tracker built with Flutter.

## Features
- **Smart Voice & Text Parsing**: Natural Bengali and English voice/text input parsing with exact integer poisha arithmetic (no floating-point rounding drift).
- **Offline-First & Private**: Embedded SQLite database via Drift with automatic seeding, category matching, and audit logging.
- **Fintech Slate Theme**: Clean, distraction-free modern UI with dark slate palette and Bengali/English localization.
- **Reports & Export**: Period breakdowns (Daily, Weekly, Monthly) and UTF-8 BOM CSV exports.

## Getting Started

### Prerequisites
- Flutter SDK 3.24+ (or Dart 3.5+)
- Android SDK / Chrome for target platform

### Running the App
```bash
# Run on connected device or Chrome
flutter run
```

### Running Tests
```bash
flutter test
```
